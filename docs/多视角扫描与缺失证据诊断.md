# 隔离仿真：区分缺失证据并做多视角对比

此功能不改实车尺寸、标定、SLAM 输入、串口或控制器，不输出通行许可。

## 启动与操作

先在原实验启动终端 Ctrl+C，再重新构建启动（不要启动两份）：

```bash
cd ~/zzs_rogMAP
bash run_passage_lab.sh
```

另开终端，执行显式启动的多视角扫描：

```bash
source /opt/ros/humble/setup.bash
source ~/zzs_rogMAP/.passage_lab/install/setup.bash
export ROS_DOMAIN_ID=219 ROS_LOCALHOST_ONLY=1
ros2 run sentry_passage_sim multiview_scan.py
```

它只通过 `/passage_sim/set_entity_state` 移动合成场景中的 `sensor_rig`，不是驱动机器人。
传感器模型依次位于 `(0,0)`、`(1.2,0)`、`(1.2,0.45)`、`(1.2,-0.45)`、`(0,0)`，始终在入口 x=2 前。
这是离散观测点，不是经过验证的底盘轨迹；仍使用 Gazebo 真值位姿而非 LIO。
每次移动后丢弃至少两秒仿真时间的过渡数据，收集至少五个不同时间戳的新鲜诊断样本。
检查区域始终是大洞口中心 `(2.6,0)`，不要在自动测试时点击 Publish Point 更换探针。
结束或一般异常时尝试恢复传感器原 XY；若强制杀死进程或 Gazebo 已退出，恢复不能保证。

## RViz 看什么

展开 `Clearance probe (observation only)` 的 Namespaces，可分别显示：

- `body_unknown_cyan`：青色小方块，车体扫掠体积内未知体素。没有点云不等于已知自由。
- `support_missing_magenta`：紫红色小方块，底部支撑层缺少有效占据证据。
- `clearance_probe`：淡色检查框和统计文字。

为了看清内部，可以暂时取消 `Classification reasons`，保留原始占据和诊断。橙色原始占据含地面、洞顶，不代表都是禁止通行障碍。
空集合会发送 DELETE，旧的缺失体素不会残留。

`/terrain/clearance/status` 的新字段：

| 字段 | 含义 |
| --- | --- |
| body_unknown | 洞内未知体素数 |
| support_missing | 缺有效支撑证据的格数 |
| support_unknown | 地面层未知 |
| support_free | 地面层已被判为自由，不是可靠支撑 |
| support_stale | 地面占据存在，但直接观测过期或无效 |
| support_outside | 支撑层位于滚动地图外 |
| blocked | 车体体积内占据 |
| stale | 全部查询中的过期/无直接观测证据数 |

四类支撑原因互斥，其和等于 support_missing。旧字段 unsupported 仅统计非占据支撑，不包含所有未知，因此判断支撑缺失请看新字段。

## 如何解释比较

脚本每个视角输出各计数中位数，最后输出相对 far 的变化量：负数代表减少。
保留原来观测有效期和地图衰减，故这是“当前有效证据”的对比，不是永久累积地图。
旧未知变成过期不能算通过，必须一起看 stale、blocked、支撑计数。
即使未知减少，也不能直接推出可通行；不修改判定阈值来强行变绿。
实际 RViz 渲染需要用户验收，自动化验证检查的是数据与计数。

## 2026-10-14 全新地图在线结果

六个 CTest 目标全部通过；新增两个 C++ 测试覆盖体积/支撑未知拆分及支撑原因计数。
实际 Gazebo 扫描完成五个视角，恢复原位；实际收到两类 Marker。此次没有启动 RViz 做渲染验收。

| 视角 | 洞内未知 | 支撑缺失（均为未知） | 过期证据 | 洞内占据 |
| --- | ---: | ---: | ---: | ---: |
| 远处 | 2640 | 226 | 0 | 0 |
| 靠近 | 1510 | 146 | 20 | 0 |
| 左侧 | 1216 | 142 | 148 | 0 |
| 右侧 | 1095 | 142 | 269 | 0 |
| 返回远处 | 836 | 226 | 1804 | 0 |

以上是各阶段有效样本的中位数；运行时序会使数值略有变化。
结论：原大洞口不是只缺某一类，而是体积与地面支撑都缺观测。靠近/侧看能够补充证据，但仍未满足全体积净空验证。
返回远处的未知下降不能单独算作改善：836 个洞内未知加 1804 个过期证据仍是 2640 个不充分证据；支撑也回到 226 格缺失。
没有把 UNKNOWN 改成 FREE，没有延长观测有效期，也没有发布自动通行许可。
